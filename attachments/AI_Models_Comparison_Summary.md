# Сводка сравнения AI-моделей: GPT-4, Llama 2, GPT-4o и Gemini (мультимодальность)

**Дата сводки:** 23 сентября 2026  
**Источник:** Полная история обсуждения + актуальные данные на 2026 год

---

## 1. GPT-4 vs Llama 2 (Meta)

### Основные различия

| Параметр              | GPT-4                          | Llama 2 (особенно 70B)                  |
|-----------------------|--------------------------------|-----------------------------------------|
| Разработчик           | OpenAI                         | Meta                                    |
| Дата релиза           | Март 2023                      | Июль 2023                               |
| Тип                   | Закрытая (proprietary)         | Открытая (open weights)                 |
| Размер                | ~1–1.76 трлн параметров (оценка, возможно MoE) | 7B / 13B / 70B                         |
| Контекст              | 8K–32K токенов                 | 4K токенов                              |
| Обучение              | Огромный проприетарный датасет | 2 трлн токенов публичных данных         |

### Производительность (бенчмарки)

- **MMLU** (5-shot): GPT-4 — **86.4%**, Llama 2 70B — **68.9%**
- **HumanEval** (кодирование): GPT-4 — **67%**, Llama 2 — **~29.9%**
- **GSM8K** (математика): GPT-4 — **92%**, Llama 2 — **56.8%**

**Вывод:**  
GPT-4 значительно сильнее по reasoning, кодингу и сложным задачам.  
Llama 2 выигрывает в цене (можно хостить самому), открытости и кастомизации. Llama 2 70B примерно на уровне GPT-3.5.

**Когда выбирать:**  
- GPT-4 — максимальное качество и надёжность.  
- Llama 2 — приватность, низкая стоимость, fine-tuning, self-hosting.

## 2. GPT-4 vs GPT-4o

### Ключевые улучшения GPT-4o (релиз май 2024)

| Параметр              | GPT-4                          | GPT-4o                                      |
|-----------------------|--------------------------------|---------------------------------------------|
| Мультимодальность     | Текст (+ зрение через GPT-4V)  | **Нативная** (текст + зрение + аудио)      |
| Скорость              | Медленный                      | ~2× быстрее (до 100+ токенов/сек)          |
| Стоимость             | Высокая ($30/$60 за 1M)        | Значительно дешевле ($2.5/$10 за 1M)       |
| Контекст              | 8K–32K                         | 128K токенов                               |
| Латентность аудио     | Высокая (каскад моделей)       | ~320 мс (человеческий уровень)             |
| Качество текста       | Очень высокое                  | Сопоставимо или лучше на большинстве задач |

**Вывод:**  
GPT-4o — это прямая эволюция GPT-4. Он быстрее, дешевле, мультимодальный из коробки и лучше работает с неанглийскими языками. К 2026 году оригинальный GPT-4 уже считается legacy и выводится из ChatGPT.

## 3. Архитектура GPT-4o

### Официальное описание (OpenAI System Card)

GPT-4o — это **autoregressive omni model**:

- Принимает на вход любую комбинацию: текст, аудио, изображения, видео.
- Генерирует любую комбинацию: текст, аудио, изображения.
- **Обучена end-to-end** сразу на текст + зрение + аудио.
- Все модальности обрабатываются **одной и той же нейронной сетью** (единый Transformer).

### Ключевые особенности архитектуры

- Единое пространство токенов для всех модальностей.
- Специальный аудио-токенизатор позволяет работать с речью в реальном времени.
- Зрение: патчи изображений → токены.
- Нет отдельных пайплайнов (как раньше: Whisper → GPT → TTS).
- Контекст: 128K токенов.
- Латентность ответа на аудио: от 232 мс (среднее ~320 мс).

**Что не раскрыто OpenAI:**  
Точное количество параметров, наличие Mixture-of-Experts, детали аудио-энкодера.

**Поздние обновления (2025):**  
Добавлена нативная генерация изображений (autoregressive, а не diffusion как в DALL·E).

## 4. GPT-4o vs Gemini (мультимодальность)

### Сравнение архитектур и возможностей (состояние на 2025–2026)

| Параметр                  | GPT-4o                              | Gemini (3.x / 3.1 Pro и аналоги)              |
|---------------------------|-------------------------------------|-----------------------------------------------|
| Подход к мультимодальности| Единая end-to-end сеть              | Изначально нативная мультимодальность        |
| Контекст                  | 128K                                | 1M+ токенов (иногда до 2M)                   |
| Аудио (голос)             | Отличная real-time речь             | Хорошая, но латентность выше                 |
| Видео                     | Хорошее понимание                   | Сильнее на длинных видео                     |
| Зрение                    | Сильное                             | Очень сильное (особенно документы, таблицы)  |
| Скорость                  | Высокая                             | Зависит от версии (Flash — очень быстрый)    |
| Экосистема                | OpenAI API + Realtime API           | Google Search, Workspace, Vertex AI          |

### Сильные стороны

- **GPT-4o**: Лучший real-time голосовой диалог, естественность, скорость реакции, качество генерации изображений.
- **Gemini**: Огромный контекст, сильная работа с длинными видео и документами, глубокая интеграция с Google-сервисами, часто лучше на сложных мультимодальных бенчмарках (MMMU-Pro и т.п.).

**Вывод на 2026 год:**  
Оба модели — сильные нативные мультимодальные системы.  
GPT-4o выигрывает в голосовом общении и удобстве.  
Gemini выигрывает в длинном контексте и работе с видео/документами.

## Общий итог (2026)

| Модель          | Лучше всего для                          | Главный минус                     |
|-----------------|------------------------------------------|-----------------------------------|
| **Llama 2**     | Self-hosting, fine-tuning, низкая цена   | Слабее по reasoning и кодингу     |
| **GPT-4**       | Максимальное качество (legacy)           | Дорого, медленно, почти устарел   |
| **GPT-4o**      | Универсальные задачи + голос + зрение    | Уже не самый новый флагман        |
| **Gemini 3.x**  | Длинный контекст, видео, Google-экосистема | Менее "живой" голос               |

**Рекомендация:**  
В 2026 году большинство команд используют комбинацию:  
- GPT-серию (или o-series) для голоса и сложных reasoning-задач  
- Gemini для длинного контекста и видео  
- Open-source (Llama / Qwen и т.д.) для self-hosting и кастомизации
