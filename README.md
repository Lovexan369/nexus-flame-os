# NEXUS FLAME OS

Единый онлайн-контур из всех веток:

| Модуль | Что внутри |
| --- | --- |
| NEXUS FLAME × XANKONG | Пульт, Shadow vault, шлюзы. Внешние эффекты всегда `executable: false`. |
| AIUIOG | Шесть агентов, терминал, карта каналов OpenClaw. |
| LeadPredict | Стол заявок, прайс, воронка холодный / тёплый / горячий. |

Creator Mode включён по умолчанию. Checkout — только Stripe, не из шлюза.

Telegram-бот из браузера не крутится: для polling нужен отдельный `BOT_TOKEN` на сервере.
